# hdfc-bank-financial-analysis
Project Name :
Financial Analysis Dashboard – HDFC Bank (FY2021–FY2025)

Project Overview :
Developed an interactive Financial Analysis Dashboard in Microsoft Excel to evaluate HDFC Bank's financial performance over five financial years (FY2021–FY2025). The dashboard provides a comprehensive view of key financial indicators such as Revenue, Net Profit, Earnings Per Share (EPS), Deposits, and Advances through dynamic visualizations and automated calculations. Users can select a financial year using a dropdown menu to instantly view updated KPIs, insights, and business conclusions.

Tools and Technologies :
	Microsoft Excel
	XLOOKUP Functions
	Data Validation (Dropdown Selection)
	Excel Charts and Graphs
	Conditional Logic (IF Functions)
	Dynamic KPI Cards
	Financial Statement Analysis
	Data Visualization Techniques

Dashboard Features :
o	Interactive Year Selection (FY2021–FY2025)
o	Dynamic KPI Cards displaying:
•	Revenue
•	Net Profit
•	EPS
•	Deposits
•	Advances
o	Revenue and Profit Trend Analysis
o	Deposits vs Advances Comparison
o	Earnings Per Share (EPS) Trend Visualization
o	Growth Analysis Charts
o	Dynamic Executive Insights
o	Dynamic Business Conclusion Section
o	Professional Banking-Themed Dashboard Layout

Data Preparation :
 	Collected financial data from HDFC Bank Annual Reports (FY2021–FY2025).
 	Extracted and consolidated key financial metrics including Revenue, Net Profit, EPS, Deposits, and Advances.
 	Structured the data into a tabular format for efficient analysis.
 	Created separate sheets for:
	Raw Data
	Calculations
	Dashboard
 	Applied Data Validation and lookup formulas to enable dynamic reporting.

Data Analysis :
	Performed year-wise financial performance analysis.
	Evaluated growth trends in Revenue and Net Profit.
	Analyzed changes in Deposits and Advances across five years.
	Assessed shareholder value using Earnings Per Share (EPS).
	Generated dynamic executive summaries based on selected financial year.
	Compared financial indicators to identify performance improvements and business expansion trends.

Dashboard Preview :
The dashboard presents a professional and interactive overview of HDFC Bank's financial performance through:
	Executive-level KPI Cards
	Financial Trend Charts
	Dynamic Year-Based Analysis
	Executive Insights and Business Commentary
	Clean and User-Friendly Interface
The dashboard enables stakeholders to quickly assess financial health, growth patterns, and key business indicators, supporting data-driven decision-making and performance evaluation.
